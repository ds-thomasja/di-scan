h2. User Story

{Draft: As a clinical user, I want a contextual workflow assistant panel to appear at key procedure steps, so that I can follow guided instructions and take actions without leaving the current workflow.}

- Interaction Model: The panel is a floating overlay (positioning is caller-owned, matching the [Toolbar] component's contract — [Toolbar]'s Assistant pill already wires {{DSIcons.activity}} to a tooltip literally named "Workflow Assistant", i.e. it is meant to open this exact panel). The user dismisses it via the top-right close Icon Button ({{onClose}}). The {{variant}} prop switches the indicator between an informational state (*standard* — tinted {{DSIcons.activity}}) and a completion state (*success* — green circle badge with a white check icon). Five content slots below the permanent indicator + title are each independently shown or hidden based on whether their corresponding prop is non-null/non-empty: {{description}}, {{media}}, {{bullets}}, the switch-with-label toggle ({{switchLabel}}), and the secondary action button ({{buttonLabel}}).

h2. Acceptance Criteria

 - *Functional:*
 -- Tapping the close button calls {{onClose}}; the panel does not remove itself from the tree — that is the caller's responsibility.
 -- When {{variant = WorkflowAssistantVariant.standard}} (default), the tinted activity indicator is visible and the success badge is not rendered.
 -- When {{variant = WorkflowAssistantVariant.success}}, the green check badge is visible and the activity indicator is not rendered.
 -- When {{description = null}}, the description block and its preceding 8 px gap ({{spacing/layout/xs}}) are both absent.
 -- When {{media = null}}, the media slot and its preceding 16 px gap ({{spacing/layout/s}}) are absent.
 -- When {{bullets}} is empty, the bullet list and its preceding 16 px gap ({{spacing/layout/s}}) are absent.
 -- When {{switchLabel = null}}, the toggle row and its preceding 24 px gap ({{spacing/layout/m}}) are absent.
 -- When {{buttonLabel = null}}, the button and its preceding 24 px gap ({{spacing/layout/m}}) are absent.
 -- Toggling the switch calls {{onSwitchChanged}} with the proposed value; {{switchValue}} is host-owned and never mutated internally.
 -- Tapping the secondary button calls {{onButtonPressed}}.

 - *States:*
 -- Close button: no background fill at rest; DS tertiary hover/pressed states per {{DSButton.windowControlClose}}.
 -- Secondary button: {{action-secondary/standard}} (white) background at rest; hover/pressed per {{DSButton.secondary}}.
 -- Toggle: renders {{switchValue}}'s current value; no internal state of its own.
 -- No disabled state is defined for this component in the source Figma; none is implemented.

 - *A11y:*
 -- Close button carries {{DSButton.windowControlClose}}'s own accessible semantics (no additional label applied by this component) — *confirm with QA whether this reads as "Close" without extra wiring*.
 -- The activity/check indicator icons are purely decorative; {{DSIcon}} renders them with no separate interactive semantics.
 -- Colour contrast for {{text/standard}} on {{surface/standard}} and for the white check icon on {{icon/success}} is asserted by the design to meet WCAG AA; not independently re-verified here.

h2. Content Logic & Edge Cases

- *Title overflow:* Wraps across up to 3 lines; truncates with an ellipsis beyond that.
- *Description overflow:* Wraps naturally across multiple lines; no maximum line count is enforced — *confirm with Design if a cap is required*.
- *Bullet count:* The Figma design shows exactly 4 bullets, but {{bullets}} accepts any length for flexibility — *confirm with Design/Product whether a different count is a valid real-world scenario, and how list height should respond if so*.
- *Empty media slot:* When {{media = null}}, no placeholder frame is rendered at all (the whole slot and its gap collapse) — this differs from the Figma mock, which always shows a placeholder frame even with no real image loaded yet. If a caller needs a "media is loading" state distinct from "no media slot at all", they should pass a placeholder widget into {{media}} themselves rather than relying on this component to render one.
- *All optional sections hidden:* The card renders with only the indicator + title, collapsing to its minimum height — *verify minimum height with Design if this is an expected real-world configuration*.
- *Long toggle/button label:* {{DSSwitch}}'s and {{DSButton}}'s own text-overflow handling applies; not overridden locally.
